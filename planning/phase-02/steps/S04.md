## Scope

OTP ستة أرقام آمنة وHMAC، صلاحية عشر دقائق، خمس محاولات وقفل 30 دقيقة دون تصفير عند resend؛ فاصل 60 ثانية وثلاث رسائل/15 دقيقة لكل حساب وغرض. هذه القيم اختيارات تقنية موثقة وليست أرقامًا مفترضة من المتطلبات. Hangfire SQL وWorker وOutbox مشفرة بـAES-GCM، بلا Dashboard. Mailpit محلي فقط؛ لا إرسال خارجي أو Brevo فعلي.

## الشرح قبل التنفيذ

المعاملة تحفظ الحالة وintent الإرسال معًا. Worker يدعي رسالة بlease ثم يرسل خارج المعاملة، ويثبت النتيجة شرط امتلاك lease. لا يمكن إرجاع بريد قبله المزود؛ فقد ACK قد يكرر الرسالة. jobs تحمل أسماء تقنية ومعرفات فقط، وpayload مشفر في Outbox؛ السجلات العامة محجوبة. مفاتيح OTP/Outbox مستقلة وثابتة خارج Git. لا تغيير مخطط Pipeline؛ logging الخاص بـHangfire مغلق لمنع fallback عام، والتشخيص التشغيلي يظل غير مكتمل.

## تسلسل التنفيذ

مراجعة حزم Hangfire 1.8.25 الرسمية وتراخيص LGPL-3.0-or-later وNewtonsoft 13.0.4 MIT؛ تثبيت lockfiles. تكوين SQL storage وActivator صريح لكل host دون JobStorage.Current أو JobActivator.Current. جدول Outbox وlease/retry، وOTP state وendpoints والتسجيل الذري. فحص موارد Docker ثم إنشاء Mailpit اختبار معزولة بports عشوائية دون لمس القديمة. تجارب SQL/HTTP/SMTP وفقد ACK وrestart والتكرار والتزامن وعدم تسريب الأسرار قبل S05.
