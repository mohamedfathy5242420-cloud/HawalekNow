## Scope

[Workflow](../../../.github/workflows/p01-baseline.yml) لـpull_request وpush main وworkflow_dispatch، permissions=contents:read، Actions رسمية مثبتة SHA، hosted Ubuntu وpwsh. Dockerfile متعدد المراحل وسياق allowlist آمن، بناء صورة SQL المشتقة الموجودة، وفحص API معزول دون volumes أو أسرار أو SQL/بريد. لا Registry أو Deployment أو branch protection أو تكاملات جديدة. لا P02 أو Identity/Persistence/OTP/Business/Frontend.

## الشرح قبل التنفيذ

CI ينفذ فحوص المطور على جهاز GitHub مؤقت. Format يرصد التغييرات دون إصلاحها في CI. Docker build ينتج صورة؛ تشغيل API يثبت الحياة والبوابة فقط، ولا يثبت استمرار SQL أو جاهزية Production. الشرح التفصيلي للكود والتجربة التعليمية في مهمة تالية مخصصة بطلب المستخدم، ولا يعوضهما التقرير.
