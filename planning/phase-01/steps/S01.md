## تسلسل التنفيذ

1. تحقق بوابة P00 والدمج ونظافة الشجرة ثم أنشئ chore/p01-s01-create-monorepo-and-solution من main.
2. سجل InProgress وافحص الأدوات دون تثبيت أو تشغيل Docker Desktop تلقائيًا.
3. أنشئ الهيكل والحل بواسطة dotnet new sln --name HawalekNow --format slnx --output backend.
4. اختر SDK 10.0.401؛ latestPatch يسمح بتحديث patch داخل 10.0.4xx فقط، ولا ينتقل إلى feature band أو major آخر؛ allowPrerelease=false. عند غياب نسخة ملائمة يفشل اختيار SDK بدل استخدام .NET 8/11.
5. افحص الحل والهيكل والتوثيق وجرّب build مع توثيق حدوده؛ راجع الفرق ثم Commit وPush وDraft PR.
6. سجل InReview وتسليم Draft؛ لا انتقال دون مراجعة المستخدم. لا Use Case أو Transaction في هذه الخطوة.
