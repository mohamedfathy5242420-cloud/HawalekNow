## الشرح قبل التنفيذ

Command يعني طلب تغيير، Query يعني طلب قراءة، Handler ينفذ الطلب، وBehavior يغلف التنفيذ لمسؤولية تقنية. «عدّل سعر منتج» مثال Command و«هات سعره» مثال Query فقط؛ لا تنفيذ Business هنا. الطلب عبر ISender.Send يدخل Logging ثم Performance ثم Validation ثم Handler. الرجوع بالعكس. Logging الخارجي يسجل النجاح أو الفشل، Performance يقيس حتى الرفض، Validation يمنع وصول المدخلات غير الصحيحة للـHandler. لا تسجل الطلب أو النتيجة أو رسائل الأخطاء؛ Password وOTP وTokens وCookies وAuthorization headers لا تدخل السجل.
D004: Workflow Step تعني Command أو Query، وليست خطوة الخطة. MediatR لا ينشئ Transaction تلقائيًا. عملية قد تضم عدة خطوات داخل Transaction واحدة؛ عدة Transactions ليست Atomic تلقائيًا. حدود المعاملة تتحدد عند تنفيذ Use Case لاحقًا.
