المتطلبات المعتمدة: الأنشطة والتصنيفات في القسم 5، واختيار المكان والمرادفات في 6، واللغتان وإدارة البيانات في 10–11؛ ROADMAP P03-S01 إلى S07 وحدود MODULES وD001–D006 وD010–D012 وD018–D019. P02 مغلقة ومدمجة ومتحققة على main=5e4250ff31f84c8806649c7ef1786574da7dd00a. كتب هذا التصميم قبل كود S01.

D019 يعتمد نسخة المصدر الجغرافي بنطاقها ونواقصها، دون إثبات اكتمال مصر. لا حسابات أو متاجر أو فروع أو منتجات أو بحث تجاري أو واجهة أو Audit عام جديد. جلسة الشرح التعليمية منفصلة؛ التصميم وتقرير الاختبارات لا يعوضانها.

## الكيانات والملكية والعلاقات

| الوحدة | النموذج |
| --- | --- |
| Catalog | Activity → Category؛ ParentId اختياري داخل النشاط نفسه، ولا حد Business للعمق. معرفات Guid وRowVersion، وFK مركبة (ParentId, ActivityId) تمنع أبًا من نشاط آخر، وحذف مقيد. |
| Locations | Governorate → City → Area؛ FK مركبة (CityId, GovernorateId) تمنع نسبة منطقة إلى محافظة غير محافظة مدينتها. مستوى City في Seed يشمل القسم/المركز كما في D019. |
| Search | SynonymGroup → SynonymTerm؛ مجموعة متعددة اللغات مع النص الأصلي ومفتاح مقارنة مطبع. لا ملكية للتصنيفات أو المنتجات. |

DbContext واحد وSchemas منفصلة وUoW الحالية. لا مدخل عام لكل جداول الوحدات. API تتعامل مع Application وعقودها؛ EF وSQL داخل Infrastructure للوحدة المالكة. لا تعديل Entity وحدة من وحدة أخرى. أي عملية متعددة التغييرات لها معاملة واحدة، دون Orchestrator أو Event Bus أو Outbox إضافية بلا حاجة.

الأسماء الإدارية عربية وإنجليزية وغير فارغة، بحد 100 محرف للعرض و160 لمفتاح المقارنة في Catalog. الاسم المعروض يحفظ نص الإدارة بعد trim؛ المفتاح FormKC مع دمج تتابع الفراغات وToUpperInvariant. لا توحيد لأحرف عربية مختلفة ولا تغيير نصوص المستخدم الحرة. SQL تستخدم nvarchar ومفاتيح BIN2 للمقارنة الدقيقة بعد التطبيع.

Catalog: كل لغة فريدة بين الأنشطة، والتصنيفات فريدة بين الأشقاء داخل النشاط نفسه. فهرسان للجذور وفهرسان للأبناء يعالجان NULL صراحة. لا حد عمق، وقراءة الشجرة مستوى واحد بصفحات؛ فحص المسار تكراري دون تحميل الشجرة كاملة.

Locations: المعرفات ومفاتيح المصدر هي أساس الهوية. لا يفرض تفرد الاسم الإنجليزي بين أقسام المحافظة؛ القسم والمركز قد يحملان الاسم الإنجليزي نفسه بمعرفين صحيحين وفق D019. لا تدمج تلك السجلات ولا تعاد تسميتها لإرضاء قيد مصطنع. تحظر العلاقات اليتيمة أو المتعارضة. تفاصيل نقل عنصر له أبناء توثق وتختبر في S03؛ لا نقل جزئي يكسر علاقاتهم.

## التفعيل والحذف والتزامن

تعطيل الأب يخفيه وكل نسله من القراءة العامة، دون تغيير IsActive المخزنة للأبناء. إعادة تفعيل الأب لا تعيد تفعيل ابن عطله Admin. نقل تصنيف داخل نشاطه يغير الأب فقط؛ يصبح ظهور الفرع تابعًا لمسار التفعيل الجديد. لا تغيير نشاط التصنيف من خلال عملية النقل.

حذف نشاط له تصنيفات، أو تصنيف له أبناء، أو مكان له أبناء يرفض 409 مع بقاء البيانات صحيحة. لا ادعاء اختبار مراجع منتجات مستقبلية غير منفذة. تستكمل الوحدات المالكة تلك المراجع عندما تنفذها.

التعديل والحذف يحتاجان RowVersion للهدف. حماية الشجرة لا تعتمد عليها وحدها: عمليات Catalog الهيكلية تحصل على قفل SQL مملوك للمعاملة باسم ثابت قبل قراءة المسار والحفظ. يمنع ذلك نقلين متزامنين على صفين مختلفين من إنشاء دورة. يختبر السباق فعليًا بسياقين واتصالين، مع التحقق من البيانات بعد الرفض. أخطاء القيود والتزامن تعاد بعقد ProblemDetails دون SQL أو تفاصيل استثناءات أو أسرار.

## HTTP والأمن المخططان

المسارات تحت /api/v1. هذه خريطة تصميم قبل التنفيذ؛ يسجل كل Step المسارات الفعلية وأدلتها عند إنجازها.

| المسار | السياسة |
| --- | --- |
| GET catalog/activities وcatalog/categories?activityId&parentId&page&pageSize&language | زائر أو مستخدم أو Admin؛ الفعال فقط، لغة ar/en، صفحة 1–100، وفرز ثابت بالمعرف. DTO عرض دون RowVersion أو حقول إدارة. |
| GET/POST/PUT/DELETE admin/catalog/activities وadmin/catalog/categories | AdminOnly الموجودة؛ القراءة تشمل المعطل ونسخة التزامن، والكتابة تحتاج HTTPS وCSRF وحد معدل مناسب. |
| GET locations/governorates وcities?governorateId وareas?governorateId&cityId | اختيار عام للفعال فقط، بصفحات وفرز ثابت والتحقق من الأبوين. |
| GET/POST/PUT/DELETE admin/locations/governorates وcities وareas | AdminOnly، ونسخة التزامن وقيود الأبوين والحذف والمعاملة. |
| GET/POST/PUT/DELETE admin/search/synonym-groups | AdminOnly؛ المجموعة ومصطلحاتها تتغير ذريًا، دون بحث تجاري. |

الإدارة تعيد 401 للزائر و403 للمستخدم غير Admin. لا Role أو UserId من DTO للترخيص. كل mutation تمر بحماية المتصفح الموجودة ومحدد معدل للبيانات المرجعية. GET لا تعدل البيانات ولا تكشف المحجوب. لا تتغير سياسات الحسابات أو الجلسات أو Logger والتوازي.

## Seed والمرادفات والإحداثيات والذاكرة

Seed صريحة، قابلة للتكرار، بمعرفات مستقرة ومعاملة تحمي الفشل الجزئي. تضيف المفقود فقط؛ لا تستبدل تعديلات Admin ولا تحذفها أو تعيد تفعيلها. يحفظ الترخيص والنسب ونسخة المصدر وبصماته. لا يفترض اكتمال مصر أو تختلق بيانات للأقسام الأربعة عشر التي لا تحمل مناطق في النسخة.

الأنشطة من المرجع: ملابس وإكسسوارات؛ إلكترونيات وموبايلات؛ أثاث وأدوات منزلية؛ قطع غيار سيارات. الإنجليزية ترجمة عرض للمعاني نفسها، وليست أنشطة جديدة.

المرادفات تحفظ النص الأصلي وتستخدم تطبيع Unicode محافظًا محددًا في S05. لا stemming أو دمج عشوائي لأحرف العربية. المصطلح المطبع لا ينتمي إلى مجموعتين في الوقت نفسه؛ تعديل المجموعة ومصطلحاتها ذري وبنسخة تزامن.

مراجعة S06 قبل الكود: افتراض centroid في النسخة الأولى من التصميم لم يكن مطلبًا إنتاجيًا مثبتًا؛ راجعت المتطلبات6 وGeo Search وROADMAP P04-S04 التي تسند موقع geography للفروع ونقاط الاستلام لاحقًا. لذلك لا يضاف حقل centroid إلى Locations ولا تستورد إحداثيات المصدر. تؤسس S06 قيمة GeoPoint مستقلة عن EF وتحويلًا جاهزًا في Infrastructure إلى SQL geography Point SRID4326؛ Longitude=X وLatitude=Y، مع رفض NaN وInfinity والخروج عن الحدود. المستهلك الإنتاجي المقرر هو P04-S04 ثم حساب المسافة في Search؛ لا يبدأ تنفيذهما هنا. التخزين والقراءة ومسافة معروفة بالمتر تثبت بنموذج وجدول داخل مشروع الاختبار وقاعدته المملوكة فقط، باستخدام DbContext الإنتاجي مع ModelCustomizer خاص بالاختبار. لا Entity أوجدول Probe أوendpoint إنتاجي، ولا Migration صورية. يثبت الاختبار أن النموذج الإنتاجي العادي لا يحتوي نوع الاختبار.

S07 تستخدم IMemoryCache مستقلة لقراءات الاختيار العامة الفعلية فقط، بSnapshot immutable ذاتId/Name وصفحة دون Entities أوobject عام. المفتاح Family/resource/language/owner/parent/page/pageSize/activeOnly؛ TTL مطلق60ثانية وحد8192وحدة بتكلفة1+عددعناصرالصفحة. الإبطال بعد نجاح Commit فقط لكلfamily، وSeed تبطل الوحدتين بعدCommit المشترك عبرعقدCatalog. generation وlookup/publish/invalidate تحتبوابةواحدة تمنع loader قديمة منملءجيلجديد؛ SQL خارجالبوابة. القراءةالجارية قدتكملبلقطتها، ولايعادإلغاءكلطلب. تختبر القراءةالمتزامنة وrollback وعمرالذاكرة وحدها. الذاكرة محليةللHost، وتشغلCLI قبلHTTP أوتنتظرTTL؛ لاادعاءاتساقموزع أوRedis. تفاصيل [سياسة الذاكرة](../../backend/REFERENCE_CACHE.md).
