Catalog تملك Activity و Category وشجرتها غير المحدودة بعمق Business، والتفرد بين الأشقاء والانتماء للنشاط. Locations تملك Governorate/City/Area و FK المركبة؛ City في المصدر تشمل القسم/المركز. Search تملك مجموعات المرادفات ومصطلحاتها فقط. لا متاجر أو فروع أو منتجات أو بحث تجاري منفذة في P03.

الإدارة تستخدم AdminOnly و HTTPS و CSRF والمعدل المرجعي المشترك. كل تعديل أو حذف يحتاج RowVersion؛ أقفال SQL تحمي سلامة العلاقات وعضوية المرادفات عبر الصفوف. الحذف المقيد يمنع الأيتام؛ حذف مجموعة مرادفات يحذف مصطلحاتها ذريًا. تعطيل الأب يخفي نسله دون تغيير حالاتهم. يلزم أن تضيف المراحل المالكة لاحقًا قيود مراجع المنتجات والفروع؛ لم تختبر مراجع غير منفذة.

Seed مثبتة وفق D019: 4 أنشطة، 27 محافظة، 365 قسمًا/مركزًا، 5716 شياخة. 14 قسمًا بلا مناطق و 18 مجموعة أسماء إنجليزية متكررة محفوظة؛ لا ادعاء اكتمال مصر. CC BY4.0 والنسب والبصمات مضمّنة. [دليل التشغيل](../../../backend/REFERENCE_DATA_OPERATIONS.md) يوضح الأمر الصريح وسياسة حفظ تعديل Admin وحذفه.

GeoPoint جاهزة لحقول P04-S04 المقررة، وتحويلها إلى geography SRID4326 داخل Infrastructure. لا حقل centroid أو جدول Probe إنتاجي أو Maps. الاختبار أثبت التخزين والمحاور والمسافة بالمتر على SQL حقيقية. [الحزم](../../../backend/P03_DEPENDENCIES.md) مثبتة؛ لا ترقية SDK/MediatR أو تغيير اعتماد الإنتاج.

[Cache](../../../backend/REFERENCE_CACHE.md) للاختيار العام فقط؛ TTL60 ثانية وحد 8192 وحدة، وإبطال بعد Commit وجيل يمنع نشر اللقطة القديمة. محلية لكل Host؛ Seed CLI قبل HTTP أو انتظار TTL، ولا اتساق موزع مفترض. لا حسابات أو صلاحيات مخزنة.
