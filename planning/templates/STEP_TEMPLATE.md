## الهدف والسبب

اكتب السلوك أو المخرج الذي سنحققه، وسبب احتياجه تجاريًا أو تقنيًا.

## مصادر واعتمادات

اذكر قرارات السجل ذات الصلة وملفات المتطلبات والخطوات السابقة التي يجب اكتمالها.

## Scope

حدد ما يدخل هذه الخطوة وما يؤجل، والملفات المتوقع تعديلها أو إنشاؤها.

## الشرح قبل التنفيذ

حدد المفهوم الجديد ومثالًا مرتبطًا بالمشروع. قدمه للمستخدم قبل تطبيقه.

## تسلسل التنفيذ

ضع أعمالًا صغيرة قابلة للمراجعة، مع السلوك المتوقع للنجاح والفشل والحالات الحدية.
للـUse Case حدد حد المعاملة: Atomic داخل Transaction واحدة، أو Workflow متعدد المعاملات مع آلية متابعة واستعادة مناسبة.

## التحقق

لكل طبقة اكتب المطلوب وأمر التشغيل الفعلي والنتيجة والدليل، أو سبب عدم انطباقها.

## Definition of Done

- تحقق المخرج والسلوك المتفق عليه.
- نجاح طبقات التحقق المطلوبة وتوثيق أي طبقة غير منطبقة.
- مراجعة التغييرات وعدم توسيع النطاق بلا قرار.
- اكتمال المراجعة البشرية المطلوبة وتوثيقها.
- تحديث CURRENT_STATE وإعداد Handoff.

## سجل التنفيذ والمراجعة

سجل ما نفذ، وما تغير عن المتوقع، والقرارات الجديدة، واعتماد المستخدم عند وروده.
لا تملأ Commit أو PR إلا بقيمة فعلية؛ يجوز تسجيل NotCreated أثناء المراجعة.

## Handoff

رابط سجل التسليم، والخطوة التالية، والمدخلات الجاهزة وأي متطلبات متبقية.
