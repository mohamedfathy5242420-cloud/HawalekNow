# نطاق HawalekNow

آخر تحديث: 2026-11-09

## فكرة المنتج

موقع لاكتشاف المنتجات والتجار بالقرب من العميل، ومقارنة السعر والتوافر لكل فرع ثم التواصل مباشرة مع التاجر.
الصفقة تتم خارج المنصة. الإطلاق متاح في جميع مناطق مصر، ولا يتوقف فتح البحث على عدد التجار أو المنتجات.

## نطاق Backend المعتمد

- هوية العميل والتاجر وAdmin، مع OTP بالبريد وموافقة Admin على حساب التاجر.
- بيانات الأنشطة والتصنيفات والمناطق والمرادفات بالعربية والإنجليزية يديرها Admin.
- متجر واحد لكل حساب تاجر، بنشاط رئيسي واحد، وفروع أو نقاط استلام متعددة.
- منتجات نصوصها الحرة في حقل واحد لكل قيمة، مع صور من 1 إلى 5 وتفاصيل إجبارية وملاحظات اختيارية.
- السعر والتوافر مستقلان لكل فرع؛ النشر يحتاج فرعًا وصورة وسعرًا وحالة وتصنيفًا صالحًا.
- بحث المنتجات والمتاجر والتصنيفات نصيًا، مع المنطقة اليدوية أو موقع دقيق ونطاق ثابت 1000 متر.
- لا تعرض مسافة بالأمتار دون موقع دقيق، ولا توسع النطاق تلقائيًا عند غياب النتائج.
- المفضلة والبلاغات للمستخدم المؤكد، ومراجعة البلاغات يدويًا مع إخفاء هوية المبلغ عن التاجر.
- إدارة المحتوى والتجار، وAudit، وإشعارات تشغيلية، وإحصائيات لحظية أو شبه لحظية تشمل الزائر المجهول.
- عدم دمج نشاط الزائر القديم بحسابه بعد التسجيل، وعدم عرض هويته للتاجر.
- حذف ناعم واسترجاع ضمن مهلة 30 يومًا حسب القواعد المعتمدة.
- API والتوثيق والاختبارات وDocker وCI والاستعداد لتكامل الواجهة.

## مؤجل

- تفاصيل Frontend والتنفيذ في Angular واختيار مكتبات الواجهة.
- تكامل Google Maps وتحديد APIs والتكلفة عند مرحلته.
- الاستضافة وObject Storage للإنتاج ومنصة تجميع Logs.
- الاشتراكات والباقات والدفع والعروض والخصومات وتطبيقات الموبايل.
- الخصائص والفلاتر الديناميكية ومحرك بحث مستقل وRedis.
- مستندات السجل التجاري والبطاقة الضريبية وموظفو المتجر بأدوار متعددة.

## خارج النسخة الأولى

سلة الشراء وCheckout والطلبات الداخلية والشحن والتوصيل وإدارة نزاعات البيع.
